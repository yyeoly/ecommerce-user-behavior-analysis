# 电商用户行为分析与销售看板

## 项目简介
基于 UCI Online Retail 数据集（54万行交易记录），从 0 到 1 完成数据清洗、建模与可视化分析，产出销售洞察与用户行为结论，从产品经理视角提出业务优化建议。

## 技术栈
- 数据清洗：MySQL 8.0
- 可视化：Power BI Desktop（DAX 度量值建模）
- 辅助工具：Excel
- AI 辅助：借助ChatGPT AI 生成初始代码框架，经本人业务逻辑调整后使用

## 分析框架
1. **数据清洗**：处理退货记录、日期标准化、异常值过滤、空值处理
2. **核心指标**：净收入、客单价(AOV)、活跃客户数、订单量、ARPU
3. **多维分析**：时间趋势 → 区域分布 → 商品结构 → 用户画像推导
4. **用户分层**：RFM 模型（Recency/Frequency/Monetary 各打1-5分）
5. **业务建议**：市场拓展、复购机制、SKU优化、退货分析

## 核心洞察
- 英国市场贡献 85%+ 收入，高度集中
- 11月为销售峰值（圣诞备货季），季节性明显
- 客单价 371.33 暗示企业采购/B端批发特征
- 有效客户仅 46 人，84% 为低价值/流失，复购机制缺失

## 文件说明
- `sql/`：MySQL 清洗、聚合、RFM 分层脚本
- `dax/`：Power BI 度量值与计算列代码
- `powerbi/`：看板截图（销售页+用户分析页）
- `docs/`：完整分析结论与产品建议
- `data/`：数据来源说明（不放原始数据，仅说明字段结构）
